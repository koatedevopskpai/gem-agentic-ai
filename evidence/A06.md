## What changed

- `src/gem_agentic_ai/mcp_tools/server.py` — an MCP server over stdio
  (`mcp.server.mcpserver.MCPServer`, `mcp==2.3.0`) with two read-only tools,
  `search_files` and `read_file`, both confined to a resolved root directory.
  Deliberate refusals use the SDK's `ToolError`, which the protocol carries as
  `isError: true` without killing the server.
- `src/gem_agentic_ai/mcp_tools/client.py` — `MCPToolset` (one live session,
  `tools/list` discovery, `ServerConfig`) and `MCPTool` (a LangChain
  `BaseTool` backed by `tools/call`). `args_model_for` builds a Pydantic model
  from each MCP `inputSchema`; the guard requires one. `ProtocolMismatchError`
  fails closed on any revision other than 2025-11-25.
- `src/gem_agentic_ai/mcp_tools/__main__.py` — `python -m
  gem_agentic_ai.mcp_tools --root <dir>`.
- `scripts/a06_demo.py` — handshake, direct calls, three refusal cases, an
  agent run that uses the tool, and an agent run that receives a tool error.
- Tests — `tests/test_mcp_server.py` (15), `tests/test_mcp_client.py` (16).
- `requirements.txt` — `mcp==2.3.0`; `pyproject.toml` — `mcp>=2.3,<3`.
- Docs — `docs/A06.md`, ADR-15 in `docs/ARCHITECTURE.md`, README section.
