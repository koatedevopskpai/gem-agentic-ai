## Restart-safe vs reconciliation

`docs/A02.md` has the full tables. In summary:

- Restart-safe: checkpoint reads and writes, thread config resolution,
  thread listing, deletion, retention sweep, completed-action records.
- Needs reconciliation: a process killed inside a tool (the step replays);
  a crash between an external side effect and the idempotency write (the
  dual-write window); approval decisions (deliberately not durable); a crash
  between checkpoint deletion and registry deletion (re-run the delete).
- Not supported: multiple hosts over one directory, and the async graph
  path with this sync saver.
